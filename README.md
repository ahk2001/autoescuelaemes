# Autoescola EMES — El Grao de Castellón

Sitio web oficial de **Autoescola EMES** (Carrer de Joan d'Àustria, 37, El Grao de Castellón, España).

## Características
- Diseño editorial responsive (Mobile-First) con identidad visual oficial (`#005CBE`, `#0B1F3A`, `#E80201`).
- **Formulario de Triaje Inteligente en Popup Modal** (4 pasos rápidos) conectado al WhatsApp oficial de secretaría.
- Catálogo completo de permisos DGT (Permiso B, Motos AM/A1/A2/A, Camión C, Tráiler C+E, Autobús D, CAP y clases de reciclaje).
- Galería real de flota, aula informática y alumnos aprobados.
- Preguntas frecuentes (FAQ) y mapa de ubicación en el Grau de Castelló.

## Estructura
```text
.
├── assets/         # Logotipo oficial e imágenes reales de flota, aula y aprobados

├── vercel.json     # Cabeceras de seguridad y caché para producción
└── README.md
```
